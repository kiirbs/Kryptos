# Kryptos

> ⚠️ Kryptos is an educational project and is **not intended for production use**.

Kryptos is an educational project aimed at designing a container for encrypted files in a clean, well-documented, and scalable manner, while exploring the principles of software engineering and cryptography.

---

## Philosophy

A secret between two is a secret of God, a secret among three is everybody's secret.

---

## Features

- KPT container
- Parser
- Serializer
- Unit tests
- XOR

---

## Project structure

- `docs`: documentation about Kryptos
- `kryptos`: Krypros library
- `samples`: sample files used during development
- `tests`: validations for features
